# Personal Portfolio Website

A responsive personal portfolio website built during the Codomax Digital
Solutions Web Development Internship.

## Overview

Showcases my background, skills, projects, and experience as a full-stack
developer, with a dedicated contact page for reaching out.

## Tech Stack

- HTML5 (semantic structure)
- CSS3 (Flexbox, Grid, media queries, transitions/animations)
- Vanilla JavaScript (DOM manipulation, form validation, scroll behavior)

## Pages

- index.html - Home, About, Skills, Projects, Experience, Education
- contact.html - Contact form with validation and social links

## Features

- Responsive layout across desktop, tablet, and mobile
- Mobile navigation menu toggle
- Smooth scroll and a back-to-top button
- Animated project cards and hover effects
- Contact form with client-side validation
- Resume download button

## Folder Structure

```
personal-portfolio/
├── index.html
├── contact.html
├── style.css
├── script.js
├── DEPLOYMENT.md
├── BUGFIXES.md
└── README.md
```

## How to Run

Just open `index.html` in your browser - no build step or server required.
